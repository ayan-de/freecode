# harness-signals

A fold of `~/.freecode/rollout/sessions/*/events.jsonl` into the numbers
behind the confidence-stepping, hill-climbable-goals and auto-poke sections
of `/bench`. Free, offline, numbers only.

**Operator reference is `HARNESS-BENCH.md` at the repo root** (§3).

```bash
pnpm bench:signals            # → apps/web/app/data/harness/signals.json
pnpm test:harness-signals
```
