# FreeCode

Welcome to the FreeCode documentation.

FreeCode is a CLI-driven AI coding assistant built around a single agentic tool-use loop, a thin-client multi-frontend architecture, and a swappable provider layer (Anthropic, OpenAI, Gemini, and a MiniMax-compatible endpoint).

> **Status:** the docs site is brand new. Pages are placeholders — content will be ported in as it's written.
