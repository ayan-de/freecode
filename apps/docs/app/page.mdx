# FreeCode

FreeCode is a CLI-driven AI coding assistant. A single agentic tool-use loop runs
in a long-lived CLI backend, and every frontend — terminal, VS Code, web, desktop,
mobile — is a thin presentation layer that talks to it over JSON-RPC. Providers
(Anthropic, OpenAI, Gemini, MiniMax, DeepSeek, Z.ai) are swappable without
touching the loop.

## The shape of the system

```
  TUI · VS Code · Web · Desktop · Mobile        (render + IPC only)
                   |
              JSON-RPC (stdin/stdout)
                   |
          CLI backend — all intelligence
   agent loop · tools · context · sessions · memory
   providers · MCP · hooks · skills · permissions
                   |
        Anthropic · OpenAI · Gemini · MiniMax
              DeepSeek · Z.ai
```
