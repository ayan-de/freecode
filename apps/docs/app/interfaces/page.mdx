# Interfaces

Every FreeCode frontend is a thin client: it renders and it speaks JSON-RPC,
and that is all. No frontend calls a provider, reads a file, or executes a tool.
That means the terminal UI, the VS Code extension, the web UI, the desktop app,
and a phone on your Tailnet all get identical behaviour from the same backend.
