# Guides

These pages cover the parts of FreeCode you actively steer: how much the agent is
allowed to do, what tools it can reach, what it remembers, and what a session
costs. Start with [agent modes](/guides/agent-modes) and
[permissions](/guides/permissions) — together they decide everything the agent can
and cannot touch.
