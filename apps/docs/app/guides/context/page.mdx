# Context & instructions

Each turn, FreeCode compiles a system prompt from the mode preamble, your
instructions file (`CLAUDE.md`, falling back to `AGENTS.md`), a cached project
file tree, git HEAD, and relevant memory. The tree is cached by HEAD and
invalidated after any mutating tool, so it is cheap but never stale.
