# Hooks

Hooks are interception points around the session, each turn, each tool call,
compaction, and sub-agents. They are the supported way to change the agent's
behaviour without editing the loop: a hook can be a shell command, an internal
callback, or an LLM prompt, and depending on the event it can block the action or
rewrite its input, output, or context.
