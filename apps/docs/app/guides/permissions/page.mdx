# Permissions & rules

Every tool call is matched against user-editable rules like
`Bash(npm run test:*)` or `Read(./secrets/**)`, merged from project and user
settings plus in-session grants. Precedence is **deny > ask > allow**, first match
wins, and a `deny` is absolute — no hook and no allow rule can override it.
Unmatched calls fall through to the mode default.
