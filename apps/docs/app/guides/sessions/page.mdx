# Sessions

Sessions are durable. Every turn is recorded as an event log alongside the thread
store, which is what makes resuming, forking a conversation at a point in time,
and exporting a session for someone else possible.

## On this page (coming soon)

- Listing and resuming with `/resume` and `freecode session list`
- Forking a session to try a different approach
- Export / import, upload / download
- Archiving and deleting
- Where sessions are stored (sqlite, json, or remote)
- Importing existing Claude Code sessions
