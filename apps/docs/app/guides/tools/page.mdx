# Tools

Tools are how the model acts on your machine. FreeCode ships 16 built-ins —
file I/O, search, code intelligence, shell, web access, sub-agents, memory — plus
whatever an MCP server exposes. Concurrency-safe tools are batched and run in
parallel; mutating tools run one at a time, in order.
