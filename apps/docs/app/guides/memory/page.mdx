# Memory

Persistent memory is a folder of small markdown notes — typed `user`,
`feedback`, `project`, or `reference` — that FreeCode writes and reads across
sessions. A derived knowledge graph indexes them locally so only the handful
relevant to the current message gets injected, instead of all of them.
