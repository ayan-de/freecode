# CLI commands

`freecode` with no subcommand launches the terminal UI. Everything else is a
subcommand.

## On this page (coming soon)

- `freecode` — launch the TUI
- `freecode run` — one-shot, non-interactive execution
- `freecode serve` — run the backend as a server
- `freecode web` — HTTP/WS bridge plus web UI
- `freecode mobile` — remote access setup wizard
- `freecode session list|delete`
- `freecode memory graph|ui-install`
- `freecode mcp add|list|remove|start|stop|status`
- `freecode trace [id] [--follow|--slow|--list|--json|--otlp]`
- `freecode uninstall`
- Global flags: `--version`, `--help`
