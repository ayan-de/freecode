# Memory

Memory is a folder of small markdown files, one fact per file, and those files are
the source of truth — readable, diffable, and editable without FreeCode running.
Everything else built on top of them (see
[knowledge graph](/internals/knowledge-graph)) is a rebuildable derivative.
