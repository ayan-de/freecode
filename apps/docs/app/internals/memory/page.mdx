# Memory & knowledge graph

Markdown files are the source of truth; the graph is a rebuildable `.graph/`
sidecar. Memories are embedded locally, wired into a graph by tags, wikilinks, and
supersede edges, then retrieved by seeding from the current message and cascading
outward with per-hop decay — one turn behind, so the hot path never waits.
