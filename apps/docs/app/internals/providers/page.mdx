# Provider layer

Every provider implements `AIProvider` and self-registers into the registry, so
the loop never names a provider. Calls go through the Vercel AI SDK; streaming,
tool calls, extended thinking, prompt caching, and usage are normalized into a
single chunk stream before the loop ever sees them.
