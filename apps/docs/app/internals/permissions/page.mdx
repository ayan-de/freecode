# Permission engine

Six steps decide every tool call: danger bypass, mode enforcement, `PreToolUse`,
the rules engine, `PermissionRequest`, then the interactive prompt. Mode
enforcement runs before rules, which is why a read-only mode cannot be unlocked by
an allow rule; and a rules `deny` is absolute, which is why no hook can undo one.
