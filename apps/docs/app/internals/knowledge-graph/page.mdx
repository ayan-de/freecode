# Knowledge graph

The graph is a `.graph/` sidecar derived from the [memory](/internals/memory)
files — delete it and it rebuilds. Memories are embedded locally, wired together
by tags, wikilinks, and supersede edges, then retrieved by seeding from the
current message and cascading outward with per-hop decay, one turn behind so the
hot path never waits on it.
