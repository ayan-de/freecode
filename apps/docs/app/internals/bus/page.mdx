# Event bus

Nothing inside core talks to a frontend directly. Modules publish events to a bus;
a bridge maps them to `StreamEvent`s and drops internal-only ones; a single
`subscribeAll` egress writes them to stdout (terminal) and SSE (web). Two-way
events — questions and permission asks — park a promise keyed by request id until
the answer comes back.
