# Agent loop

The loop is a stateful, turn-based cycle. Each turn it compiles a system prompt
(project tree, git HEAD, memory), makes a **single** streamed provider call, and
lets the model drive by emitting native tool calls. Those run — in parallel
batches where safe — and their results fold into the next turn. It stops when a
turn comes back with no tool calls, a health check trips a stuck pattern, or the
iteration cap is hit.
