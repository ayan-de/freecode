# Context engine

`tree-cache.ts` builds a cached `ProjectContext` — name, path, file tree, git
HEAD — keyed by HEAD and invalidated after any mutating tool. The `PromptCompiler`
assembles the system prompt from the mode preamble, instructions, project summary
and tree, and session memory, as cacheable blocks.
