# Providers & API keys

Six providers are registered out of the box: **Anthropic**, **OpenAI**,
**Gemini**, **MiniMax**, **DeepSeek**, and **Z.ai**. Each implements the same
`AIProvider` interface and self-registers, so switching provider or model is a
setting — never a code change. All of them go through the Vercel AI SDK with real
streaming, native tool calling, and usage accounting.
