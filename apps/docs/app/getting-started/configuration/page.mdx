# Configuration

FreeCode reads settings from two scopes: `.freecode/settings.json` in the
project (commit it — it is your team's policy) and `~/.freecode/settings.json` for
your machine. Project settings win where they overlap, and in-session grants layer
on top of both without being written to disk unless you ask.
