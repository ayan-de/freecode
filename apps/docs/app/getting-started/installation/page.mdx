# Installation

FreeCode ships as a single self-contained binary built with Bun, installed by
`scripts/install.sh` (macOS/Linux) or `scripts/install.ps1` (Windows). Installed
versions live under `~/.freecode/builds/versions/`, so upgrades and rollbacks are
just a directory swap. `freecode uninstall` removes it again.
