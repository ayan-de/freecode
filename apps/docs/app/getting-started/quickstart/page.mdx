# Quickstart

Run `freecode` inside a project and you get the terminal UI: a prompt, a
streaming transcript, and an agent that reads and edits files by calling tools.
This page walks one real task from prompt to applied diff, including the
permission prompt you will hit the first time the agent wants to write.
